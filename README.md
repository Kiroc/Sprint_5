# Финальный проект 5 спринта "UI-тестирование"
## Файлы:
- helpers.py - файл со вспомогательными данными (ссылки, данные пользователя, рандомизатор пользователя)
- conftest.py - файл с фикстурами
- locators.py - файл с локаторами элементов в DOM
- tests/ - каталог с тестами
- tests/test_construct.py - файл с проверками конструктора
- tests/test_login.py - файл с проверками авторизации
- tests/test_profile.py - файл с проверками личного кабинета
- tests/test_register.py - файл с проверками регистрации
### Для запуска тестов должны быть установлены:
- `pytest`
- `selenium`
### Команда для запуска тестов:
`pytest -v`
